# Pre-stream checklist

- [ ] Episode log created: `tools/new-episode.sh "<title>"`
- [ ] Today's goal written in the episode log, overlay ticker updated
- [ ] Notifications OFF (OS, Slack, email, phone)
- [ ] Streaming browser profile open; no personal tabs
- [ ] No `.env` / credentials files open in editor tabs
- [ ] Terminal and editor font size bumped for readability
- [ ] Mic and cam check in OBS
- [ ] Ledger timer reset
- [ ] Stream title and category set, go-live post drafted
